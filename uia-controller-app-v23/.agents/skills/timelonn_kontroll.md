# Kontrollrutiner for Timelønn og Sensorhonorarer

Denne ferdigheten inneholder sjekkpunkter for utbetaling av timelønn til vitenskapelige assistenter og eksterne sensorer ved UiA.

## 1. Vitenskapelige assistenter (Stillingskode 1019 / 1020)
1. **Forhåndsgodkjent kontrakt:** Skriftlig ansettelsesavtale må foreligge i P360 / Unit4 med spesifisert timeramme, timerat og kostnadssted før arbeid starter.
2. **Timeregistrering:** Timer føres fortløpende av den ansatte i selvbetjeningsportalen.
3. **Attestasjon:** Emneansvarlig / prosjektleder bekrefter at timer er reelt utført og i samsvar med oppdraget.
4. **BDM-godkjenning:** Leder med BDM godkjenner utbetalingen. Skjønnsmessige utbetalinger uten timeliste er ikke tillatt.

## 2. Eksterne sensorer (Artskonto 533 - Oppgavepliktige honorarer)
1. **Formell oppnevning:** Sensor må være formelt oppnevnt og registrert i Felles Studentsystem (FS) / Unit4.
2. **Sensurbevis:** Eksamensadministrasjonen verifiserer at sensuren er gjennomført og protokollført i Inspera / FS innen lovbestemt frist (15 virkedager).
3. **Skatte- og kontoopplysninger:** Personalia og kontonummer verifiseres mot arbeidstakerregisteret før anvisning.
4. **Anvisning:** BDM-haver anviser honoraret iht. gjeldede satser per besvarelse eller per time.
